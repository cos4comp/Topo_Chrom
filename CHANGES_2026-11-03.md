# Repository update — 2026-11-03 (major-revision deposit)

Prepared for the revised manuscript PCOMPBIOL-D-26-01280R1. The uploaded
archive contradicted the revised manuscript in four places; all are fixed
here, and the real-data analysis has been added so that the Data
Availability Statement is accurate.

## Contradictions fixed

1. **README "Status note"** claimed the parameters were placeholder
   choices, "not taken from a specific manuscript" and "not calibrated to
   any real dataset". The manuscript (Methods 4.1, Data Availability)
   deposits this repository as the paper's pipeline with parameters
   calibrated to GSE63525. The note is replaced by an accurate description
   of both analyses in the repository.
2. **`config/generative_parameters.json` `_comment`** carried the same
   placeholder disclaimer; replaced with the calibration description of
   Methods 4.1.
3. **README "Example outputs"** showcased partial correlations and
   "all p < 1e-15" on the planted synthetic data — exactly the inferential
   statistics the revision removed from Table 1 (editor concern 2). The
   section now presents the regression as a recovery test against the
   planted R² target (realized 0.739 vs target 0.72) and states that no
   p-values or partial correlations are reported.
4. **`results/table1_regression.csv`** contained `partial_r`, `t`, and
   `p_value` columns. Those three columns were removed (coefficient, se,
   and standardized-coefficient values untouched) so the deposited table
   matches the revised manuscript's Table 1, and
   `scripts/run_pipeline.py` was minimally edited so that re-running the
   pipeline writes the same recovery-report columns (the partial
   correlations are still computed by `tcit/statistics.py`, which is
   library code, but are no longer written to the table or printed).
5. **Maximum-entropy framing.** The README presented max-ent inference
   recovery metrics as a completed analysis. The revised Methods 4.3
   states the max-ent model is the theoretical construction of Section 2.4
   and that no manuscript result is an output of that inference. The
   README now frames those numbers as an implementation sanity check.

## Added: `realdata/` (manuscript Section 2.10, Table 3, Methods 4.7)

- `realdata/scripts/`: `hic_reader.py` (purpose-written .hic reader,
  Juicebox format v7/v8, HTTP range requests), `01c_liftover_gc.py`
  (GENCODE v29 GRCh38→hg19 CrossMap liftover + GC), `02a_cache.py`
  (sparse matrix cache), `02_features.py` (per-gene TCIT features at
  10 kb), `03_model.py` (whole-chromosome holdout + cross-line transfer),
  `04_extra_stats.py` (univariate/standardized/sensitivity statistics).
- `realdata/data/`: per-gene feature tables `features_GM12878.tsv`
  (19,449 genes) and `features_K562.tsv` (18,691 genes), `genes_hg19.tsv`,
  `gc_windows.pkl`, and the two GSE63525 Arrowhead domain-call files.
- `realdata/results/`: `metrics.csv` and `results_summary.md` (full
  measured record, including the weak cross-line transfer and the
  expressed-only sensitivity).
- `realdata/README.md`: provenance (GSE63525; ENCSR000AEF; ENCSR000CPH),
  external inputs, pipeline order, and the honest reading of the results.
